# Origem do conteúdo do editor

Gerado por `tools/gen_content.py` (templates, adesivos, fundos, `index.json`). Nada foi copiado do app
original analisado (ARQUITETURA, restrição legal).

| Pasta | Origem | Licença |
|---|---|---|
| `templates/` | escritos por nós (documentos `pp-editor` v1, JSON do Fabric 7) | do projeto |
| `stickers/` | SVG desenhados à mão no gerador | do projeto |
| `scenes/` | cenários procedurais da fase 2 (`tools/gen_scenes.py`; ver `scenes/SOURCES.md`) | do projeto |
| `fonts/<Família>/` | repositório `github.com/google/fonts`, pasta `ofl/<família>/`, arquivo sem modificação (baixado em 2026-10-14) | SIL OFL 1.1 — `OFL.txt` ao lado de cada fonte |

Fontes: Montserrat, Inter, Open Sans, Nunito, Raleway, Oswald, Bebas Neue, Anton, Playfair Display,
Lobster, Pacifico, Dancing Script. Lobster, Dancing Script e Raleway declaram Reserved Font Name: a OFL
proíbe usar o nome reservado em versão **modificada**; aqui os arquivos vão sem modificação.
Os nomes de arquivo foram simplificados (`Montserrat[wght].ttf` → `Montserrat/Montserrat.ttf`), o que
a OFL permite (o nome do arquivo não é o nome da fonte).
